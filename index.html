PUSAT BANTUAN

Bagaimana kami dapat membantu?

Panduan singkat menggunakan layanan E-Bimwin.

Apakah bimbingan ini dapat diikuti melalui HP?

Ya. Website dirancang responsif dengan pendekatan mobile-first agar dapat digunakan melalui smartphone, tablet, maupun komputer secara nyaman.

Apakah nilai pre-test menentukan kelulusan?

Tidak. Pre-test digunakan untuk memetakan pengetahuan awal Anda. Fokus utama bimbingan adalah memahami modul dan materi keluarga sakinah.

Apakah progres tersimpan jika saya keluar?

Dalam prototipe ini progres tersimpan di penyimpanan browser lokal pada perangkat yang sama. Untuk sinkronisasi lintas perangkat, sistem dapat dihubungkan ke database Supabase.

Bagaimana jika lupa password?

Fitur pemulihan akun memerlukan backend autentikasi dan verifikasi nomor HP/email. Fitur tersebut belum aktif pada mode demo lokal.

Butuh bantuan petugas KUA?

Hubungi KUA Kecamatan Makale melalui kanal layanan resmi.
